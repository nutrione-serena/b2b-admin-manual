04. 주문관리

주문관리 화면 사용법

견적에서 주문확정된 건, 또는 관리자가 직접 등록한 주문 건의 출고·운송 정보를 관리하고, CI·PL 등 서류 생성부터 출고 완료까지의 진행 상태를 처리하는 화면입니다.

1 주문 처리 흐름

주문확정→ 출고준비중 (발주 전)→ 출고준비중 (발주 후)→ 출고완료
주문취소 — 주문확정 이후 상태라면 언제든 발생할 수 있는 종료 상태

"출고준비중" 상태 안에서 CI·PL 등 서류 생성 → 발주요청 메일발송(발주) → 운송장 정보 등록 → 자동으로 출고완료 전환 순서로 진행됩니다.

주의. 상태에 따라 수정 권한이 달라집니다.
· 주문확정 상태에서는 영업 담당자(운영팀)가 주문 내용을 수정할 수 있습니다.
· 출고준비중으로 전환되면 무역팀·영업관리팀만 수정할 수 있습니다. 다른 유관팀이 확인 중인 상태이므로, 수정이 필요하면 권한을 가진 담당자에게 요청해야 합니다.
· 발주요청 메일발송 이후에는 담당자 누구도 수정할 수 없습니다. 이미 물류팀에 정보가 전송되었기 때문입니다.
발주 후 수정이 필요하면 "주문취소 → 복사 재등록"을 권장합니다. 발주요청 메일발송 이후 계속 값을 고치다 보면 실수가 생기기 쉽고, 서류 자동 생성에도 문제가 발생할 수 있습니다. 수정이 필요한 경우 해당 건을 주문취소한 뒤, 목록의 복사 기능으로 같은 내용을 불러와 새로 등록하는 편이 안전합니다.

2 주문 목록 조회

기본은 최근 1주일 주문건만 조회됩니다. 과거 건은 주문일 기간을 "전체"로 바꿔 검색하세요.

목록의 인보이스번호(견적/주문번호)를 클릭하면 주문 상세 화면으로 이동합니다.
Tip. 목록의 "복사" 기능으로 복사되는 범위
· PO, 추가서류, 입고증은 수동 등록한 파일에 한해 그대로 복사됩니다.
· CI, PL, 입고증은 자동 생성 방식이라 복사되지 않습니다 (새 주문에서 다시 생성해야 합니다).
· 그 외 입력 정보는 모두 그대로 복사됩니다.
· 복사로 생성된 건은 원 견적과 연결되지 않은 별도의 주문으로 인식되며, 관리자가 주문등록 한 것과 동일하게 등록됩니다.

3 주문 등록 / 상세 화면 구성

주문 등록·상세 화면은 견적과 동일하게 기본정보 / 수출자·수입자 정보 / 출고·운송 정보 / 품목 정보 / 포장·가격 정보 / 서류 정보 6개 영역으로 구성되어 있습니다. 화면 배치와 조작 방법은 견적관리 페이지의 4번 항목과 동일하므로, 참고해주세요.

Tip. 품목 정보의 필수값 / 선택 포함값 구분도 견적과 동일하게 적용됩니다. 선택 포함값은 화면에서 체크한 항목만 서류에 포함되어 생성되니, 서류 생성 전 체크 여부를 꼭 확인해주세요. (자세한 내용은 견적관리 페이지 품목 정보 참고)

주문 화면에서 추가로 확인해야 할 부분은 다음과 같습니다.

인보이스번호(견적/주문번호)견적과 주문은 하나의 번호를 그대로 공유합니다. 상태에 따라 클릭했을 때 연결되는 화면만 견적상세 / 주문상세로 달라질 뿐, 번호 자체는 바뀌지 않습니다. 번호 규칙 : 거래처번호_년월일 6자리 + 숫자 3자리
출고가능일주문등록 시점에는 보이지 않고, 주문확정 이후에 나타납니다. 기본값은 "출고요청일 출고예정" 문구이며, 별도 날짜를 지정하려면 날짜와 변경 사유를 모두 입력해야 합니다.
운송장 정보출고준비중(발주완료, 즉 발주요청 메일발송 이후) 상태부터만 입력할 수 있습니다. 운송장 정보를 입력해 저장하면 자동으로 상태가 출고완료로 전환됩니다.

주문취소출고준비중저장

출고준비중 (발주 전) 상태

다른 값은 모두 수정할 수 없지만, 추가서류 항목만 수정 가능하기 때문에 저장 버튼이 남아있습니다.
발주 전 / 발주 후 차이를 꼭 기억하세요. "발주요청 메일발송" 버튼을 누르는 순간 발주상태가 발주완료로 바뀌고 품목정보·포장정보·서류정보 등 대부분의 항목이 잠깁니다. 메일 발송 전 수량·규격·인코텀즈를 마지막으로 한 번 더 확인해주세요. 발송 후 수정이 필요하면 주문취소(이 경우 물류팀에게 자동 안내 메일이 발송됩니다) 후 다시 진행해야 할 수 있습니다.
주의. CI·PL 서류를 먼저 "서류생성" 하지 않으면 발주요청 메일발송이 되지 않습니다. 단, 포장유형이 카톤 + 내수거래 여부 Y + 부가세 과세 조합인 경우만 예외로 서류 생성 없이 발주 처리가 가능합니다. 이 조합에 해당하지 않는다면, 발주 전 서류 생성 여부를 꼭 확인하세요. (자세한 서류 생성 조건은 서류 생성 안내 참고)
주의. 주문취소는 "주문확정" 상태에서는 누구나 가능하고, "출고준비중" 상태부터는 무역팀·영업관리팀만 가능하므로, 일반 담당자가 취소가 필요하면 해당 팀에 요청해주세요.

5 참고표 — 인코텀즈 / 파레트 규격

인코텀즈별 입력란 안내문구

FOB / FAS선적항 (주로 수출국 PORT명)
FCA지정장소 (예 : INCHEON / BUSAN)
EXW지정장소 (수출자의 공장, 물류센터)
DAP / DDP / DPU지정 목적지 (주로 수취인 주소, 공장, 앤드유저 주소)
CPT / CIP지정된 목적지 (주로 포트)
CIF / CFR지정목적항 (주로 수입국 PORT명)
주의. 인코텀즈 종류에 따라 입력해야 할 값의 의미가 완전히 다릅니다. FOB에는 "선적항"을 넣어야 하는데 DAP/DDP용 "수취인 주소"를 잘못 넣는 실수가 흔하니, 인코텀즈를 바꿀 때는 입력값도 함께 재확인하세요.

파레트 종류별 규격 안내 (참고용)

파레트 규격에는 기본값이 없습니다. 종류를 선택해도 값이 자동으로 채워지지 않으므로, 아래 표를 참고해 가로·세로·무게를 직접 입력해야 합니다. 입력한 가로×세로 규격을 기준으로 부피(CBM)가 계산되므로 정확히 입력해주세요.

높이·무게 제한은 앞의 파레트 규격과 달리 기본값이 있는 별도 항목입니다. 필요하면 직접 입력해 값을 바꿀 수 있으며, 입력한 값이 곧 실제 출고 시 물류팀이 파레트를 구성할 때 넘지 않는 상한 기준이 됩니다.

6 서류 생성 안내 — CI/PL · 인수증 · 추가서류

서류 정보 탭에서 생성하는 서류는 CI+PL, 인수증, 추가서류 세 가지이며, 각각 노출·필수 조건과 생성 방식이 다릅니다.

CI+PL

노출 시점주문 상태가 "출고준비중"으로 전환되면 항목이 노출됩니다.
생성 없이 발주 가능 (선택)포장유형이 카톤이고, 내수거래 여부가 Y이면서 부가세가 과세인 조합인 경우에만 서류 생성 없이 발주 처리가 가능합니다.
생성 필수위 조합 외 나머지 모든 경우는 CI+PL을 생성해야만 발주 처리가 가능합니다.

인수증

노출 조건출고동봉서류에서 "인수증"을 체크한 경우에만 노출됩니다. 체크하지 않으면 생성 자체가 불필요합니다.
동작 방식노출된 경우의 생성·발주 조건 및 자동/수동 생성 방식은 CI+PL과 동일하게 적용됩니다.

자동 생성 / 수동 업로드 (CI+PL, 인수증 공통)

서류생성 (자동)필수 입력값이 모두 채워졌는지 확인한 뒤 버튼을 누르면 화면 입력값 기준으로 자동 생성됩니다. 생성 후에는 재생성 / 수동업로드 버튼이 함께 노출됩니다.
수동업로드디바이스에서 파일을 선택해 직접 올릴 수 있으며, 엑셀 파일만 업로드 가능합니다 (엑셀 외 파일은 업로드 불가 안내). 업로드한 파일이 최종 서류로 고정되고, 등록한 엑셀 파일 기준으로 PDF도 자동 변환되어 함께 제공됩니다.
자동 재생성클릭 시 최종 품목 정보 기준으로 다시 자동 생성됩니다 (수동업로드로 대체했던 경우에도 재생성 가능).
제공 형식생성된 서류는 엑셀(xlsx), PDF 두 가지 형식으로 함께 제공됩니다.
추가서류선택 입력 항목입니다. 여러 파일을 한 번에 드래그로 등록할 수 있고, 등록된 파일은 파일명 기준 가나다순으로 정렬되며 X 클릭 시 바로 삭제됩니다. 등록하지 않아도 발주·출고 진행에는 문제가 없습니다. 단, 주문취소 상태가 되면 등록된 파일은 조회만 가능하며 추가 등록·삭제는 할 수 없습니다.
가장 놓치기 쉬운 부분. 서류를 생성한 뒤 품목 정보(수량·단가 등)를 수정하면 서류가 자동으로 미생성 상태로 초기화됩니다. 발주 전 반드시 재생성해주세요.

7 자동 발송 이메일 정리

발주요청 메일발송 버튼 노출·발송 조건

노출 조건주문 상태가 출고준비중 + 발주상태 발주대기일 때, 권한 대상자(무역팀·영업관리팀) 기준으로만 노출됩니다.
서류 생성 필요버튼을 클릭하려면 서류 생성이 먼저 완료되어 있어야 합니다. CI+PL 서류를 동봉하도록 선택했는데 서류 생성 전에 클릭하면 "생성 필요" 안내만 뜨고 메일폼으로 연결되지 않습니다.
첨부파일 구성포장유형(카톤 / 파레트)에 따라 발송되는 첨부파일이 달라지며, 두 경우 모두 관리자가 선택한 동봉서류 기준으로 첨부됩니다.
정상 처리 시위 조건을 모두 만족하면 메일폼 팝업으로 바로 연결됩니다.

발주 요청 메일발송 클릭 시 팝업 조건

버튼을 누르면 발송 전 내용을 확인·수정할 수 있는 팝업이 뜹니다. 수신자·제목·본문이 미리 채워진 상태로 열리며, 발주요청 메일처럼 수동 발송이 필요한 메일은 이 팝업에서 내용을 편집한 뒤 최종 발송해야 합니다.
보내는사람메일을 클릭한 담당자 정보 기준으로 자동 출력됩니다.
받는사람주문등록자, 물류팀담당자, 영업관리담당자 기준으로 출력되며 수정 가능합니다. 콤마로 구분해 등록하면 전체에게 전달됩니다.
참조담당 본부장, 주문등록 담당팀 기준으로 출력되며 수정 가능합니다 (콤마 구분 시 전체 전달).

자주 하는 실수 체크리스트
Q. 발주요청 메일을 보냈는데 수량을 잘못 넣은 걸 발견했어요.
발주요청 메일발송 이후에는 대부분의 항목이 잠깁니다. 무역팀/영업관리팀을 통해 주문취소 후 다시 진행해야 하며, 이 경우 물류팀에게 자동으로 취소 안내 메일이 발송됩니다.
Q. 서류생성 버튼을 눌렀는데 "발주요청이 불가능합니다"라고 나와요.
CI·PL 서류가 아직 생성되지 않은 상태입니다. 서류 정보 탭에서 먼저 서류를 생성해주세요.
Q. 일반 담당자인데 출고준비중 상태의 주문을 취소하고 싶어요.
출고준비중 상태부터는 무역팀·영업관리팀만 취소할 수 있습니다. 해당 담당자에게 요청해주세요.
Q. 파레트 규격을 입력해야 하는데 자동으로 채워지는 값이 없어요.
정상입니다. 파레트 규격은 기본값이 없어 종류를 선택해도 자동으로 입력되지 않습니다. 참고표를 보고 가로·세로·무게를 직접 입력해주세요.
