03. 견적관리 (견적 승인/반려)

견적관리 화면 사용법

거래처가 사이트에서 접수했거나 관리자가 직접 등록한 견적 건을 검토하여 승인 또는 거절하고, 최종적으로 주문확정까지 진행하는 화면입니다.

1 견적 처리 흐름

견적은 누가 등록했는지에 따라 시작 상태가 다릅니다.

① 거래처가 사이트에서 접수한 경우

접수→ 관리자 검토(승인·거절)→ 거래처 검토(거절·주문확정)→ 주문확정

② 관리자가 직접 등록한 경우 (관리자 검토 단계 생략)

등록→ 거래처 검토(거절·주문확정)→ 주문확정
주의. 관리자가 직접 견적을 등록하면 등록과 동시에 상태가 "거래처 검토"로 바뀌어 곧바로 거래처에 공개됩니다. 거래처가 접수한 건과 시작 상태가 다르다는 점을 기억해주세요.
Tip. 여기서 "거래처에 공개된다"는 것은 고객 사이트(front)가 개발된 이후를 기준으로 한 설명입니다. front 개발 전인 현재는 상태가 "거래처 검토"로 바뀌어도 거래처가 직접 확인할 화면이 없으므로, 담당자가 이메일 등으로 별도 안내해야 합니다. front 오픈 이후에는 단계가 바뀌는 즉시 거래처가 front에서 바로 확인할 수 있게 됩니다.

어느 단계에서든 거절되면 아래 상태로 종료되며, 거절 이후에는 내용 수정과 주문확정이 불가능합니다.

2 견적 목록 조회 / 등록

기본은 최근 1주일 접수 건만 보입니다. 과거 건을 찾으려면 기간을 "전체"로 바꾸고 검색하세요. 목록의 인보이스번호(견적/주문번호)를 클릭하면 상세 화면으로 이동하고, 관리자가 직접 등록하려면 목록 상단의 견적등록 버튼을 누릅니다. (등록 화면도 상세 화면과 탭 구성이 동일합니다.)

Tip. 인보이스번호를 클릭했을 때 연결되는 화면은 현재 상태에 따라 다릅니다. 주문확정 이전(견적 상태)인 건은 견적상세 화면으로, 주문확정 이후인 건은 주문상세 화면으로 연결됩니다.
견적/주문 유형견적 : 정식 판매를 위한 건 / 샘플 : 판매 목적이 아니라 소량(몇 개)만 보내는 건
견적/주문 방식거래처 접수 : 고객사가 고객 사이트(front)에서 직접 접수한 건 (front 오픈 이후부터 발생) / 관리자 등록 : 관리자가 이 화면에서 직접 등록한 건
견적/주문 상태 접수 : 거래처가 접수해 관리자 검토를 기다리는 상태
관리자검토 : 관리자가 승인·거절을 검토 중인 상태
거래처검토 : 관리자 승인 후 거래처의 최종 확인을 기다리는 상태 (관리자 등록 건은 등록과 동시에 이 상태로 시작)
주문확정 : 거래처가 승인하여 주문으로 전환된 상태
관리자거절 / 거래처거절 : 각 검토 단계에서 거절되어 종료된 상태
접수취소 : 거래처가 접수를 취소한 상태
통화(등록 시)KRW / USD / EUR 중 필수 단일 선택. 이후 모든 금액·주문단위가 이 통화 기준으로 고정되므로 등록 전 신중히 선택하세요.

3 견적 상세 화면에서 꼭 확인할 항목

상세 화면은 6개 영역(기본정보 / 수출자·수입자 정보 / 출고·운송 정보 / 품목 정보 / 포장·가격 정보 / 서류 정보)으로 구성되며, 상단 탭을 클릭하면 해당 영역으로 화면이 자동으로 이동합니다. PO번호·PO파일은 거래처가 등록한 경우 수정 불가(값만 확인 가능)하며, 관리자가 등록한 경우에만 주문확정 전까지 수정할 수 있습니다.

수출자·수입자 정보 — "동일하게 사용" 체크박스

Tip. "배송지(SHIP TO)/통지처(Notify Party) 정보에 동일하게 사용" 체크박스는 기본적으로 체크되어 있습니다. 체크된 상태면 서류에 "Same As Consignee"로 표기되고, 체크를 해제하면 강조된 영역처럼 별도 입력란이 나타나며 직접 입력한 내용이 그대로 서류에 반영됩니다.

견적 단계에서는 이 입력이 필수가 아닙니다. 값을 입력하지 않은 채 PI 서류를 생성하면 Ship-to, Notify Party 항목에 "TBN"이 대신 출력됩니다. 반면 주문 단계로 넘어가면 이 입력이 필수로 바뀌므로, 주문확정 전에는 반드시 정확한 값을 입력해주세요.

출고·운송 정보 — 출고요청일 · 인코텀즈

주의. 출고요청일을 접속일 기준 +2일 미만으로 입력하면 "출고확인 후 출고준비까지 최소 2일이 필요합니다"라는 경고가 뜹니다. 강제로 막는 것은 아니지만, 확인 없이 그냥 넘기면 실제 물류 처리 시간이 부족할 수 있으니 무역팀과 사전 협의가 필요합니다. 인코텀즈(FOB/FCA/EXW/DAP/DDP 등)를 선택하면 옆의 입력란이 필수로 바뀌며, 종류에 따라 입력해야 하는 내용(선적항 vs 지정장소 vs 수취인 주소)이 다르므로 헷갈리지 않도록 주의하세요.

품목 정보 — 판매/증정 구분

품목분류판매 / 증정 전환 가능. 증정으로 바꾸면 개당판매가가 0원으로 고정되고, 서류의 품목별 Remarks 항목에 "FOC"로 자동 표기됩니다. 이는 관리자 화면에 표시되는 것이 아니라 서류 생성 시 자동으로 붙는 문구이며, 관리자 화면에서 Remarks를 직접 입력한 경우에는 서류에 "FOC / (입력한 Remarks 값)" 형태로 함께 표기됩니다.
Carton (ea)주문수량 ÷ 카톤당 입수로 자동 계산됩니다. 나누어떨어지지 않으면 "이대로 진행하시겠습니까?" 확인 팝업이 뜹니다.
Tip. 품목 정보의 각 항목은 서류 생성 시 필수값과 선택 포함값으로 나뉩니다. 필수값은 항상 서류에 포함되지만, 선택 포함값은 화면에서 체크한 항목만 골라서 서류에 포함되어 생성됩니다. 체크를 빠뜨리면 해당 정보가 서류에서 누락될 수 있으니, 서류 생성 전 어떤 항목이 체크되어 있는지 확인해주세요. (주문관리도 동일하게 적용됩니다.)

포장·가격 정보 — 포장유형에 따라 화면이 바뀜

포장유형을 "카톤"으로 바꾸면 파레트 종류·규격 등 파레트 관련 입력란이 화면에서 사라져 불필요한 항목을 등록하지 않아도 됩니다.

최종 결제금액은 부가세 설정에 따라 달라집니다. 영세는 부가세가 0원이라 금액에 영향이 없고, 과세는 부가세 10%가 계산되어 합산된 금액이 최종 결제금액이 됩니다.

서류 정보 — 생성 방식과 제공 형식

자동 생성기본정보·품목정보 등 화면에 이미 입력된 값을 기준으로 서류가 자동 생성됩니다.
수동 업로드필요한 경우 직접 작성한 서류 파일을 업로드할 수 있으며, 이때는 업로드한 파일이 최종 서류 내용이 됩니다. 엑셀 파일만 업로드 가능합니다.
제공 형식생성된 서류는 엑셀(xlsx), PDF 두 가지 형식으로 함께 제공됩니다.
추가서류선택 입력 항목입니다. 필요한 경우에만 등록하면 되며, 등록하지 않아도 견적·주문 진행에는 문제가 없습니다.
가장 놓치기 쉬운 부분. 품목 정보(수량·단가 등)를 수정하면 이미 생성해둔 PI 서류가 자동으로 미생성 상태로 초기화됩니다. 수량을 나중에 고쳤다면 반드시 서류를 다시 생성한 뒤 발송해야 정보 불일치를 막을 수 있습니다.

버튼은 오직 현재 견적 상태에 따라서만 나타나거나 사라집니다 (담당 팀에 따른 제한은 없습니다).

관리자검토 상태
견적취소관리자거절관리자승인저장
아직 승인·거절을 누르지 않은 상태로, 관리자거절 또는 관리자승인을 눌러 다음 단계로 이동할 수 있습니다. 관리자승인 클릭 시 → 상태가 "거래처검토"로 바뀌며 거래처에 견적 내용이 공개됩니다.
거래처검토 상태
거래처거절주문확정저장
아직 승인·거절을 누르지 않은 상태로, 거래처거절 또는 주문확정을 눌러 다음 단계로 이동할 수 있습니다. 주문확정 클릭 시 → 견적은 종료되고 주문상세 형태로 등록되어 주문상세 화면으로 연결됩니다.
참고. "관리자검토" 상태의 관리자거절 버튼은 front로 접수된 건에서 사용되는 버튼으로, 거절 시 거래처에 안내가 자동 발송되는 프로세스는 추후 개발 예정입니다.
주문확정 시 발송되는 확정 메일도 나중에 추가될 예정이며, 현재는 메일이 자동 발송되지 않습니다.
되돌릴 수 없습니다. 관리자거절 / 거래처거절을 클릭하고 사유를 입력해 확정하면, 해당 견적은 더 이상 수정하거나 주문확정으로 진행할 수 없습니다. 거절 전 거래처명·품목·수량을 한 번 더 확인해주세요. (재작업이 필요하면 목록의 복사 기능으로 동일 내용을 불러와 새 견적으로 재등록할 수 있습니다.)
자주 하는 실수 체크리스트
Q. 관리자가 견적을 등록했는데 왜 벌써 거래처에게 보이나요?
관리자 등록 건은 "관리자 검토" 단계 없이 등록 즉시 "거래처 검토" 상태가 되기 때문입니다. (front 오픈 전인 현재는 화면상 상태만 바뀔 뿐 거래처가 직접 보는 것은 아니므로, 필요하면 담당자가 별도로 안내해주세요.)
Q. 품목 수량을 고쳤는데 예전 PI 파일이 그대로 발송됐어요.
품목정보를 수정하면 PI 서류가 자동으로 초기화됩니다. 서류 정보 탭에서 반드시 재생성 후 발송해주세요.
Q. 거절을 잘못 눌렀어요. 되돌릴 수 있나요?
되돌릴 수 없습니다. 목록의 "복사" 기능으로 동일한 내용의 견적을 새로 등록해 다시 진행해야 합니다.
Q. 통화를 잘못 선택하고 등록했어요.
통화는 등록 이후 금액·단가 계산 기준이 되므로 변경 시 전체 금액에 영향이 있습니다. 등록 전 반드시 확인해주세요.
